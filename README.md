# Motorola Sales Dashboard – Power BI

This Power BI dashboard provides a comprehensive view of Motorola's mobile sales across India.

## 📊 Key Insights
- **Total Sales**: ₹769M
- **Transactions**: 4,000+
- **Top Brands**: Apple, OnePlus, Samsung, Vivo
- **Filters**: Brand, Mobile Model, Day Name, Payment Method
- **Visualizations**:
  - Sales by City (Map)
  - Quantity by Month (Line Chart)
  - Customer Ratings (Bar Chart)
  - Payment Method Split (Pie Chart)
  - Mobile Model Sales
  - Day-wise Sales Trends

## 📁 Files Included
- `Motorola_Sales_Dashboard.pbix` – Main Power BI file
- `dashboard.png` – Screenshot of the report layout

## 📌 Tools Used
- Power BI Desktop
- DAX Calculated Columns
- Custom Slicers & Filters


1. Download the `.pbix` file.
2. Open it in Power BI Desktop.
3. Explore and apply filters to get deeper insights.
